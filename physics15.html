⚡ 磁效應與電磁感應

第15章 電流的磁效應　＋　第16章 電磁感應

第15章：最容易搞混的幾組公式

① B 到底除不除 π、除的是誰

長直導線（外部一點）
B = μ₀i2πR
R＝導線到該點的垂直距離
圓形線圈（圓心）
B = μ₀i2r
r＝線圈半徑，分母沒有 π
長螺線管（管內）
B = μ₀ni
n＝單位長度匝數(匝/公尺)，不是總匝數；也沒有 R 或 r
差在哪一個字：直導線是「除以 2πR」，圓形線圈是「除以 2r」（少一個 π），螺線管是「乘以 n」（根本不用除）。三個公式長得像親戚，代錯分母是這章最常見的失分。

② 安培力 vs 勞侖茲力——誰乘 L、誰乘 v

安培力（整段導線）
F = iL·B·sinθ
對象是一段「載流導線」，L 是導線長度，θ 是導線與 B 的夾角
勞侖茲力（單一電荷）
F = qv·B·sinθ
對象是「一個帶電粒子」，v 是粒子速度，θ 是速度與 B 的夾角
判斷關鍵：題目給的是一段「導線＋電流 i」→ 用 F=iLBsinθ；題目給的是一顆「帶電粒子＋速度 v」→ 用 F=qvBsinθ。兩者形式像雙胞胎，代錯對象（把 L 當 v 代，或反過來）是常見錯誤。

③ 迴旋半徑 r 與週期 T——誰跟速率有關

半徑
r = mvqB
跟速率 v 成正比，v 變快、圈就變大
週期
T = 2πmqB
式子裡沒有 v！
特別標記：週期 T 與速率無關——粒子跑快跑慢，繞一圈的時間都一樣（只跟質量、電荷、磁場有關）。題目問「多久後第一次通過某軸」，十之八九是在考這個「T 與 v 無關」的性質，不用去解 v。

④ 判方向：右手定則 vs 另一次右手定則

安培右手定則（找磁場方向） 拇指指電流方向，四指彎曲方向＝磁場繞行方向（環繞導線）
右手開掌定則（找受力方向） 四指指電流(或速度)方向，再彎向 B，拇指方向＝受力 F 方向（F=IL×B 或 F=qv×B）
差在哪：第一種是「電流生磁場」，只用拇指＋四指彎曲；第二種是「磁場對電流/電荷施力」，是三個方向做叉積（電流→磁場→力，像 XYZ 三軸）。兩種都叫「右手定則」但動作完全不同，考卷常常故意混著考。

第15章 公式卡片（附使用時機與常見代錯點）

長直導線的磁場

B = μ₀i2πR　（μ₀=4π×10⁻⁷ T·m/A）
什麼時候用：題目出現「長直導線」＋「距離 R 處的一點」。
常代錯：R 必須是「垂直距離」，不是斜線距離；多條導線疊加時要先判斷各自方向再向量相加，不能直接把數值加減。

圓形線圈圓心的磁場

B = μ₀i2r　（N 匝則再乘 N）
什麼時候用：題目出現「圓形線圈」＋「求圓心 O 的磁場」。
常代錯：分母是 2r 不是 2πr（跟長直導線公式搞混，多除一個 π）；若只有半圈或部分弧，要先乘上「弧所佔比例（弧度/2π）」。

長螺線管內部的磁場

B = μ₀ni　（n = N/L，單位長度匝數）
什麼時候用：題目出現「螺線管」「每公分繞幾匝」「單位長度匝數」。
常代錯：n 要換算成「每公尺」的匝數，題目常給「每公分」要自己乘 100；多層繞線要把各層匝數密度加總。

安培力（載流導線在磁場中受力）

F = iLB sinθ　（方向：右手四指指電流方向，彎向 B，拇指為 F）
什麼時候用：題目給一段導線的電流、長度，問它在磁場中「受多少力」。
常代錯：θ 是電流方向與 B 方向的夾角，不是導線與桌面的夾角；封閉線圈在均勻磁場中「合力恆為零」，但「合力矩不一定為零」，兩者常被搞混。

勞侖茲力（帶電粒子在磁場中受力）

F = qvB sinθ　（方向：右手四指指 v，彎向 B，拇指為 F；負電荷方向相反）
什麼時候用：題目給一顆帶電粒子（q、v），問它瞬間受多少磁力，或粒子做圓周/螺旋運動。
常代錯：負電荷要把方向「反過來」；勞侖茲力恆與 v 垂直，所以「不對電荷做功」——若題目同時有電場 E，電場才會改變粒子速率。

帶電粒子的圓周／螺旋運動

r = mvqB　　T = 2πmqB　　（螺距 d=v∥T）
什麼時候用：粒子速度垂直 B → 純圓周運動；速度與 B 有夾角 → 螺旋運動，把 v 分成平行/垂直 B 兩個分量。
常代錯：只有「垂直 B 的分量」才決定 r 和圓周運動，「平行 B 的分量」不受力、等速前進，決定螺距；把整個 v 拿去算 r 是常見錯誤。

線圈力矩（電流計、馬達原理）

τ = NiAB sinφ　（N 匝、A 面積、φ 是線圈法線與 B 的夾角）
什麼時候用：線圈被磁場「轉」的問題（力矩平衡、電流計偏轉角）。
常代錯：φ 是「線圈平面法向量」與 B 的夾角，不是線圈平面本身與 B 的夾角，兩者恰好差 90°，是最容易顛倒 sin/cos 的地方。

第16章：最容易搞混的幾組公式

① Φ=BAcosθ vs ε=−N·ΔΦ/Δt —— 有沒有電動勢看的是「Φ 在不在變」

磁通量（當下的量）
Φ = BAcosθ　（單位 Wb）
Φ 只是描述「此刻」穿過線圈的磁場總量
感應電動勢（變化的量）
ε = −NΔΦΔt
ε 是 Φ「隨時間變化的速率」
差在哪：Φ 很大但保持不變（ΔΦ=0）時，ε=0，完全沒有感應電動勢；線圈靜止放在強磁場中不會發電，一定要讓 Φ 隨時間改變（轉動、移動、磁場強弱變化）才有 ε。題目常故意給一個「Φ 很大」的情境誘導你以為有很大的電動勢，這是本章最常見的失分點。

② ε=BLv vs ε=NABω·sin(ωt) —— 直線運動 vs 轉動

動生電動勢（導體棒直線運動）
ε = BLv
導體棒在磁場中「平移」，B、L、v 互相垂直
交流發電機（線圈轉動）
ε = NABω·sin(ωt)
線圈以等角速度 ω 轉動，ε 隨時間呈正弦波變化
判斷關鍵：題目說「導體棒在軌道上滑動／移動」用 ε=BLv，算出來是定值；題目說「線圈以角速度 ω 轉動」用 ε=NABω·sin(ωt)，是隨時間變化的函數。兩者形式都含 B、L(或A)、v(或ω)，但一個是直線切割磁場線、一個是轉動改變磁通量，不能互用。

③ 自感 ε=−L·ΔI/Δt vs 變壓器 V₁/V₂=N₁/N₂ —— 看電流變化率 vs 看圈數比

自感（線圈對自己感應）
ε = −LΔIΔt
電流「變化得多快」決定 ε 大小，跟圈數比無關
變壓器（兩線圈互相感應）
V₁/V₂ = N₁/N₂
兩線圈的「圈數比例」決定電壓比例，是靜態關係
差在哪：自感談的是同一個線圈「電流本身變化的速率」，單位時間變化越快、ε 越大；變壓器談的是兩個線圈之間「圈數的比例」，只要圈數比固定，電壓比就固定，不需要知道電流變化多快。兩個公式都有字母 L 或 N，注意自感的 L 是電感（henry），變壓器的 N 是匝數，符號別搞混。

④ 變壓器的電壓比 vs 電流比 —— 同向 vs 反向

電壓比
V₁/V₂ = N₁/N₂
電壓跟圈數「同向」，圈數多電壓就高
電流比
I₂/I₁ = N₁/N₂
電流跟圈數「反向」，圈數多電流反而小
差在哪：理想變壓器功率守恆 V₁I₁=V₂I₂，把電壓比代進去就能推出電流比恰好是電壓比的倒數——圈數多的一側（高壓側）電壓高、電流小；圈數少的一側（低壓側）電壓低、電流大。常見錯誤是把「電壓比同向」的規則直接套到電流上，方向沒有反過來。

第16章 公式卡片（附使用時機與常見代錯點）

磁通量

Φ = BAcosθ　（單位 Wb）
什麼時候用：題目給磁場 B、線圈面積 A、線圈法線與 B 的夾角 θ，求穿過線圈的磁通量。
常代錯：θ 是「線圈法線」與 B 的夾角，不是線圈平面本身與 B 的夾角（跟力矩公式 τ=NiABsinθ 的 θ 是同一種角）；線圈平面與 B 平行時法線與 B 垂直，θ=90°，cosθ=0，Φ=0，這時磁通量反而是最小、不是最大。

法拉第電磁感應定律

ε = −NΔΦΔt
什麼時候用：題目問「線圈的感應電動勢多大」，且給了磁通量隨時間的變化量（或可以自己算出來）。
常代錯：Φ 很大但「沒有在變」（ΔΦ=0）時 ε=0，光看 Φ 大小判斷有沒有電動勢是錯的；負號代表感應電動勢的方向會對抗磁通量變化（就是楞次定律），計算大小時通常直接取絕對值。

楞次定律——感應電流方向判斷（三步驟）

感應電流方向　永遠「反抗磁通量的變化」
什麼時候用：題目要你畫出感應電流的方向（順時針／逆時針），不是只要電動勢大小。
三步驟：① 先判斷原本磁通量的方向，以及它正在「增加還是減少」；② 感應電流的效果永遠是反抗這個變化——磁通量增加就在線圈內生成反方向磁場來抵抗，磁通量減少就生成同方向磁場來補強；③ 用右手定則，由剛剛判斷出的感應磁場方向，回推電流的環繞方向。最常犯的錯是只看「原磁場方向」就直接定電流方向，忘記要先問清楚「變化」是增加還是減少。

動生電動勢與導體棒在軌條上

ε = BLv　　I = BLvR　　F = B²L²vR
什麼時候用：導體棒在磁場中平移（B、L、v 互相垂直），或導體棒在兩條平行軌條上滑動、接成迴路求電流與受力。
常代錯：ε=BLv 只在 B、L、v 三者互相垂直時成立，v 若有分量不垂直於 B 要先分解；安培力 F=B²L²v/R 的方向永遠反抗導體棒的運動（楞次定律的具體體現），當外力與安培力平衡（合力為零）時導體棒達到「終端速度」，此後等速前進、電流不再改變，不是加速度最大的時刻。

交流發電機

ε = NABω·sin(ωt)　　最大值 ε₀ = NABω
什麼時候用：線圈在均勻磁場中以角速度 ω 等速轉動（交流發電機模型），求瞬時電動勢或最大電動勢。
常代錯：ε 最大值出現在線圈平面「平行」於 B（磁通量 Φ 剛好為零、變化率最快）的瞬間，不是磁通量 Φ 最大的瞬間——這跟磁通量公式 Φ=NABcos(ωt) 剛好差 90°（sin 與 cos 的關係），是最容易搞混的地方。

自感與線圈儲能

ε = −LΔIΔt　　U = 12LI²
什麼時候用：線圈自身電流正在變化（開關瞬間、電路變化），求線圈對自己感應出的電動勢，或求線圈當下儲存的磁能。
常代錯：自感電動勢的負號代表它會「反抗電流的變化」（電流要增大時它阻礙增大，要減小時它阻礙減小），跟外加電源方向無關；U=½LI² 是「瞬時」儲能公式，電流變小時儲能也會跟著變小，不是只增不減。

理想變壓器

V₁V₂ = N₁N₂ = I₂I₁
什麼時候用：題目給變壓器兩端線圈的圈數（或電壓、電流其中任兩個量），求另一個未知量。
常代錯：電壓比跟圈數比「同向」（圈數多電壓高），電流比跟圈數比「反向」（圈數多電流反而小）；理想變壓器功率守恆 V₁I₁=V₂I₂，看到「圈數比」先確認題目問的是電壓還是電流，比例方向抓反是最常見的錯誤。

觀念地圖：這章在講什麼

主幹只有兩件事：電流「產生」磁場（上半部三種常見形狀）；磁場反過來對電流或電荷「施力」（下半部兩條路線）。看到題目先問自己：這題是在算磁場，還是在算力／力矩／運動？

四大題型，先認出「這題是哪一型」

Ⅰ．磁場疊加型

關鍵字：「求某點的磁場」「長直導線」「圓形線圈」「螺線管」「合成磁場」「磁場為零的位置」
  1. 先判斷每個電流源在該點各自產生的 B 方向（安培右手定則）。
  2. 選對公式：直線用 2πR、圓心用 2r、螺線管用 ni。
  3. 方向相同用加法、方向相反用減法；不同方向要向量合成（畫圖分解 x、y 分量）。
  4. 若題目問「磁場為零的位置」，代表兩個 B 大小要相等、方向要相反，先列這個等式再解未知數。
代表範例：磁場範例三、六

Ⅱ．安培力／力平衡型

關鍵字：「導線受力」「磁力與重力/彈力/摩擦力平衡」「軌條上滑動」「懸吊導線」
  1. 先求出該處磁場 B（通常要先用題型 Ⅰ 的公式），再用 F=iLBsinθ 求安培力。
  2. 畫受力圖：安培力、重力(mg)、摩擦力/張力/彈力，通常是這幾個力。
  3. 抓住「平衡」或「恰好開始滑動／恰好不轉」這句話 → 代表合力（或合力矩）等於零，直接列平衡方程式。
  4. 封閉線圈在均勻磁場中「合力恆為零」——如果看到這個條件，直接跳過力的計算。
代表範例：安培力範例九、十一

Ⅲ．線圈力矩型

關鍵字：「線圈可轉動」「力矩平衡」「電流計」「線圈面與 B 夾角」「恰好不轉動/恰好平衡」
  1. 先找出線圈的「法向量」方向，量出法向量與 B 的夾角 φ（不是線圈平面本身的夾角）。
  2. 用 τ=NiABsinφ 求磁力矩。
  3. 找出對抗磁力矩的另一個力矩來源（重力矩、彈簧扭力矩…），兩者相等就是平衡方程式。
  4. 畫「側面圖」把立體問題壓成平面幾何，力臂會清楚很多。
代表範例：力矩範例一、四

Ⅳ．帶電粒子運動型（勞侖茲力）

關鍵字：「帶電粒子」「質譜儀」「速度選擇器」「圓周運動」「螺旋運動」「回到原點」
  1. 先看粒子的速度方向和 B 的夾角：垂直 → 純圓周運動；有夾角 → 拆成平行/垂直 B 兩分量，垂直分量繞圈、平行分量直線前進（合成螺旋）。
  2. 用 r=mv/qB 求半徑；問「時間」優先想 T=2πm/qB（跟 v 無關）。
  3. 若同時有電場 E：先確認是「速度選擇器」(qE=qvB 找特定速度) 還是「加速電場」(qV=½mv²找速率)。
  4. 負電荷的旋轉方向與正電荷相反，畫圖時務必先標電荷正負。
代表範例：勞侖茲範例三、六

範例逐題拆解

最容易卡住的四題

這四題是整章公認最容易算錯、想錯方向的題目，先搞懂它們卡在哪，比多算十題新題更有效。

卡點① 兩個螺線管，功率要開多大才能做出一樣的磁場

兩根螺線管外型（截面、管長）一樣，但線徑粗細不同、匝數不同，用同一種銅線繞成。這題最容易卡在：一開始會想直接套「B=μ₀ni」去湊功率關係，但漏算了「電阻其實跟線徑平方成反比」這件事——導線越粗，電阻反而越小。

正確路徑：先分別寫出電阻 R=ρL/A（A 跟半徑平方成正比），再寫出磁場公式湊出 N/L 相同時的關係，最後才組合出功率比 P=I²R。三個關係式要串起來，只寫一個公式是解不出來的。

→ 對照範例：磁場計算 · 範例八

卡點② 可繞軸轉動的正方形線圈，力臂到底怎麼量

導線被折成正方形三邊、可以繞 OO′ 軸轉動的題目，卡點在「力臂」——線圈偏轉 θ 角之後，每一段導線的重心到轉軸的水平距離不再是直接的長度，要用 sinθ 投影，而且不同邊的力臂還不一樣長（因為到轉軸的距離不同）。

正確路徑：先把立體圖轉成「從轉軸方向看過去」的側視圖，再對每一段導線分別標出「重力力臂」和「磁力力臂」，最後列一次力矩平衡方程式，不要想一次到位。

→ 對照範例：線圈力矩 · 範例四

卡點③ 電場＋磁場同時作用，套在細棒上的小球滑動

小球套在鉛直細棒上，同時受電場力（固定）、磁力（隨速度變化）、重力、摩擦力、細棒的正向力。卡點在於：正向力（棒對球的支撐力）「不是定值」——因為電場力和磁力都會影響小球對棒的側向擠壓，所以摩擦力也跟著不是定值，不能直接套 f=μN 常數處理。

正確路徑：先列出垂直細棒方向的力平衡（找出正向力 N 的表達式，裡面會有 v），再代入沿棒方向的牛頓第二定律；當加速度為零時（v=0）得到最大加速度，當合力為零時得到終端最大速度。

卡點④ 原子核分裂成兩塊，動能怎麼分配

靜止的碳原子核分裂成氦原子核和鈹原子核，兩者反方向飛出。卡點在於：質量數（4 和 8）跟半徑、頻率、動能的關係要分別推，很容易把「動量守恆」和「能量分配」混在一起套錯公式，尤其是最後求「轉變成動能」時忘記兩邊都要算、只算了一邊。

正確路徑：先用動量守恆 m₁v₁=m₂v₂ 配合質量比 1:2，求出速度比與半徑比；再用「週期只跟 q/m 有關、與 v 無關」判斷頻率比；最後動能要「兩個粒子的動能相加」才是總轉變動能。
